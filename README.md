Deep Learning-Based Classification of Blood–Brain Barrier Penetration Using SMILES-Derived Molecular Images
       Cheminformatics and Deep Learning Project | 2026 – Completed
Developed an image-based deep learning pipeline for binary classification of compounds based on blood–brain barrier penetration (BBBP).
Processed SMILES (Simplified Molecular Input Line Entry System) representations and generated 2D molecular structure images using Python and RDKit.
Implemented and compared CNN architectures, including a custom CNN, AlexNet, InceptionV3, and VGG16, for molecular image classification.
Applied class weighting to address class imbalance and evaluated model performance using test accuracy, classification reports, and confusion matrices.
Deployed an interactive prediction application that accepts uploaded molecular structure images and returns the predicted class with a confidence score.
Tools and Technologies: Python, RDKit, SMILES, TensorFlow/Keras, CNN, AlexNet, InceptionV3, VGG16, Pandas, NumPy, Scikit-learn, Molecular Image Processing, Model Deployment.
